Start here

Open Terminal → go-jsa → press Return

Then type the commands below. Ctrl-C stops anything, and your work so far stays saved.

Your files

In the profile folder.

The search

search/

What the AI search looks for, in plain sentences. After editing, run:

uv run jsa deploy

Your resume

resume.docx

The starting point for every job. Type [COMPANY], [TITLE] or [DATE] to have them filled in.

Your cover letter (optional)

cover_letter.docx

Copied into every job’s folder, with a PDF. The same placeholders work here. The AI never rewrites it.

Your skills

resume_skills.md

Skills you really have, one per line or separated by commas. The AI may add these to a resume.

02Review
uv run jsa review

Each new job opens in Chrome. Read it, then answer in Terminal.

a Apply
s Skip
b Back
q Quit

Then type one sentence on why. The search learns from it.

Acme — Communications Manager Location: Remote (US) Decision [a/s/b/q]: s Feedback (…): Great mission, but the salary is too low

Changed your mind later? uv run jsa revise --last

+Add a job
uv run jsa add <link>

Use the employer’s own link, not LinkedIn or Indeed.

Check the company and title, then press Return.

“Use this posting to refine the search?” Press Return if you want more jobs like it. Type n for a one-off.

It’s marked Apply, so it skips review. Run Generate to make its folder.

03Generate
uv run jsa generate

Makes a folder for each Apply in Documents › Job Applications and adds it to your Tracking Sheet.

Look at the resume files in the folder

.docx + .pdf

Ready. Send the PDF.

.docx only

Changes to check. See 04.

If it says no job description, the AI couldn’t read that posting. Paste the posting into a plain-text file named job_posting.md in its folder, then run the command it shows, starting with uv run.

04Edit in Word
  1. 1Open the .docx. Review tab.
  2. 2Accept or Reject each change. Its comment says why.
  3. 3Delete the comments.
  4. 4File › Save As › PDF, choosing Best for electronic distribution so links keep working. Send that.

Communications Manager, Northwind Foundation

• Wrote newsletters donor newsletters for 40,000 readers 1

• Ran the organization’s social media 2

• Planned weekly staff meetings 3

1 Posting: “donor newsletters”
Uses the job’s own words.
2 For you to decide; this is not a change.
Name Instagram here, if true.
3 Posting: “external communications”
Internal work distracts here.

1 A change. Accept or reject.

2 A question. Your call.

3 A removal. Reject to keep it.

05Apply

Submit, then fill in your two columns in the Tracking Sheet.

CompanyTitleAdded Date AppliedStatus
AcmeCommunications ManagerOct 21 Oct 23Applied ▾

The AI fills the rest. You fill the red columns.

06Refine
uv run jsa refine
  1. 1Open the profile/refine folder. Each file is one of your search files, with the AI’s suggestions marked.
  2. 2Fix each marked block, and save.
  3. 3When every block is fixed:uv run jsa refine --acceptuv run jsa deploy

A marked block

<<<<<<< current ← what the search uses now - Communications Manager ======= - Communications Manager, nonprofit or public sector >>>>>>> proposed ← the AI’s suggestion

Keep one side, or write your own. Then delete the three marker lines:

- Communications Manager, nonprofit or public sector

To throw out the whole suggestion instead: uv run jsa refine --reject
